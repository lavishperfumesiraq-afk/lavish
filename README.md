# 🌟 Lavish Perfumes - موقع عطور فاخر

موقع إلكتروني احترافي لعرض منتجات العطور لمشروع **Lavish** في البصرة، العراق.

## 📋 نظرة عامة

موقع رقمي فاخر بتصميم راقي يعرض أكثر من 550 عطر مع تفاصيل كاملة، نظام بحث وفلترة متقدم، وتجربة مستخدم سلسة على جميع الأجهزة.

## 🚀 كيفية الاستخدام

### 1. توليد بيانات المنتجات

لتوليد بيانات المنتجات من ملف الإكسل، قم بتشغيل:

```bash
python3 process_excel.py
```

سيقوم هذا بـ:
- قراءة ملف `/home/user/perfumes_list.xlsx`
- معالجة 550 منتج
- إنشاء ملف `js/products-data.js` مع كل البيانات

### 2. فتح الموقع

ببساطة افتح ملف `index.html` في المتصفح، أو استخدم خادم محلي:

```bash
# باستخدام Python
python3 -m http.server 8000

# ثم افتح: http://localhost:8000
```

### 3. النشر

لنشر الموقع:
1. اذهب إلى تبويب **Publish** في الأعلى
2. اضغط على زر النشر
3. ستحصل على رابط مباشر للموقع
