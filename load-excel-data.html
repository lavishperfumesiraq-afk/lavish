Lavish Perfumes - Data Loader

📌 ملاحظة مهمة:

الموقع يعمل حالياً ببيانات تجريبية. لتحميل جميع المنتجات الـ 550 من ملف الإكسل، اتبع الخطوات التالية:

📋 خطوات تحميل البيانات الكاملة:

  1. افتح Terminal أو Command Prompt
  2. انتقل إلى مجلد المشروع:
    cd /path/to/lavish-perfumes
  3. قم بتشغيل سكريبت التحويل:
    python3 process_excel.py

    أو:

    python process_excel.py
  4. انتظر حتى انتهاء العملية

    سيتم إنشاء ملف js/products-data.js تلقائياً

  5. أعد تحميل صفحة index.html

    وستظهر جميع المنتجات الـ 550

✅ الملفات الجاهزة:
  • ✓ index.html - الصفحة الرئيسية
  • ✓ css/style.css - التنسيقات
  • ✓ js/main.js - الوظائف
  • ⏳ js/products-data.js - البيانات (تحتاج للتحديث)
  • ✓ process_excel.py - سكريبت التحويل

🛠️ متطلبات التشغيل:

  • ✓ Python 3.x
  • ✓ مكتبة Pandas: pip install pandas
  • ✓ مكتبة openpyxl: pip install openpyxl
